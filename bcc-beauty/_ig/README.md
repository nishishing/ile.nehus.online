# BCC Instagram — 下書き生成（投稿はしない）

**何をするもの**: ポータルの素材（`_build/writeups.json` の23サービス）から、Instagram の
**カルーセル投稿（1080×1350 PNG を6枚前後）とキャプションの下書き**を作る。**投稿は人が手で行う**
（オーナー確定 2026-09-21: 下書きまで自動・投稿は人／画像は文字中心カードを自動生成／カルーセル形式）。

⚠️ **このフォルダは公開しない**。`bcc-beauty/` 直下は全部そのまま配信されるので、
`_ig/` は `.vercelignore` に入れてある（追加ファイルを置くときも同じ）。

## 使い方

```sh
node bcc-beauty/_ig/plan.mjs 3          # ① 今週のネタ票を出す（前回投稿が古い順）
#   → 出たネタ票を Claude に渡して drafts/<sid>.json を書かせる（②文面）
node bcc-beauty/_ig/render.mjs          # ③ カードPNG + 確認用 preview.html を out/ に出す
open bcc-beauty/_ig/out/preview.html    # ④ 人が見て、出すものを選ぶ
```

`out/` は生成物なのでコミットしない（`.gitignore`）。画像は **`<sid>-1.png` から順番どおりに**
並べてアップロードする（ファイル名の番号＝カルーセルの順番）。

## 1本の組み立て（面の種類）

`drafts/<sid>.json` の `slides[]` に、この4種類を並べる。**2〜10枚**まで（Instagram の上限に合わせて10で止める）。

| type | 中身 | 使いどころ |
|---|---|---|
| `cover` | 表紙。`title`＋`lead`＋カテゴリ。右下に「SWIPE →」 | 必ず1枚目 |
| `list` | `label`／`heading`／`items[]`（3つ程度） | 「こんな状態なら」＝課題の提示 |
| `point` | `label`／`heading`／`body`（2〜3行） | 中身の説明。2〜4枚 |
| `choose` | `label`／`heading`／`pairs[{when, pick}]` | **同じカテゴリのどれを選ぶか**。25サービスあるので迷わせない |
| `cta` | `heading`／`note`／`steps[]`（`**ここ**` で太字）。**濃色に反転** | 最後の1枚＝辿り着き方 |

標準は **7枚**（表紙／課題／要点×3／選び分け／辿り着き方）。枚数が2枚未満・10枚超のときは
`render.mjs` がエラーで止まる（枚数の取り違えに気づけるように）。

## 文面のルール（ポータルの恒久ルールと同じ）

- **料金・「無料」を書かない**（実額の案内は各サービスの公式LINE側）。`plan.mjs` は
  金額を含む素材に「【価格・投稿に書かない】」を付けて渡す
- **サービス提供者の個人名を書かない**（会社名・サービス名は可）
- 断定的な効果の約束をしない。数字は writeups にある実績の範囲だけ
- 絵文字を使わない。和文はゴシック（カード側で担保）
- 誘導は**具体的に**。「プロフィールのリンクから」だけで終わらせない。実際の経路は
  **プロフィールのリンク（`drive-blue.online/test/`）→ BCC の公式LINE → サービス一覧 → 該当サービス**
  （2026-09-21 実測。⚠️ **LP からポータルへの直リンクは無い**ので「ポータルを開いて」とは書かない）

## 下書きの在庫（2026-09-23 時点）

**23サービス分が揃っている**（ポータル25件のうち、`writeups.json` に資料がある全件）。
カテゴリごとに「選び分け」の面を共通化してあるので、同じカテゴリの本はどれを見ても選び方が分かる。

| カテゴリ | 本数 | 選び分けの軸 |
|---|---|---|
| 開業支援 | 3 | 初期費用なし／融資と事業計画／設計施工まで一括 |
| 不動産 | 2 | 物件を借りる／不動産事業を持つ |
| 内装 | 1 | 動線重視（ほか2社はポータルへ誘導） |
| 財務・福利厚生 | 2 | 税務調査と節税／固定費と福利厚生 |
| 材料 | 2 | 仕入れ全体／エフェクトブリーチ・イリーダ |
| ヘアスタイル販売 | 1 | 写真が足りない／投稿を自動化／見せ方 |
| 教育 | 3 | オンライン／店に講師を呼ぶ／採用と定着 |
| 集客 | 8 | **HPB系**（中身を作る／学んで自走／自動化）と **SNS系**（採用も／個人のタレント性／Instagram） |
| 予約 | 1 | キャンセル料／更新の自動化／掲載の費用対効果 |

⚠️ PLUM PLAN と Layer Design Works は `writeups.json` に資料が無いため下書きなし（選び分けの面では名前を出している）。

## 出したら記録する

`posted.json` に `{"<sid>": "YYYY-MM-DD"}` を書き足す。`plan.mjs` はこれを見て
**前回が古いもの・未投稿のものから**次のネタを選ぶ（同じサービスの連投を避けるため）。
