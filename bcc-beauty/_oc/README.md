# BCC オープンチャット — 投稿の下書き（投稿はしない）

**何をするもの**: BCC のコンテンツ（ポータルのサービス・サロピット等）から、オープンチャットに出す
**本文＋画像1枚（1080×1080）**の下書きを作る。**投稿は人が手で行う**（オープンチャットに投稿用の API は無い）。
依頼: オーナー 2026-10-26「その上げるための内容、文章、画像っていうのを毎回指示して、提案と生成までお願いします！」

⚠️ **このフォルダは公開しない**（`.vercelignore` に `_oc/` 済み）。`out/` は生成物でコミットしない。

## 使い方

```sh
node bcc-beauty/_oc/render.mjs            # drafts/ 全部 → out/<id>.png と out/preview.html
node bcc-beauty/_oc/render.mjs 01-refundhub
```

## 下書きの形（`drafts/<連番>-<sid>.json`）

| キー | 中身 |
|---|---|
| `hook` | 画像の大見出し。**問いかけか言い切り**。`**ここ**` に水色の下線 |
| `sub` | 画像の小見出し（何のサービスか1行） |
| `points[]` | 画像の要点。**3つまで** |
| `service` / `tag` | 画像の左下・右上 |
| `text` | トークに貼る本文。**1行目＝通知や一覧で見える部分なので、ここで止める** |
| `when` | おすすめの投稿時刻（仮説。反応を見て直す） |

## 反応を上げるための型（仮説・数字で見直す）

- **1行目で止める**: 悩みの問いかけ（「〜していませんか？」）か、数字・具体名
- **1投稿1テーマ**。要点は3つ。画像と本文で同じことを言う（画像だけ見ても分かる）
- **最後に軽い反応のお願い**（リアクションだけで良い／「うちだとどうなる？」をコメントで）
- **ポータルへのリンクには `?utm_source=openchat&utm_campaign=<id>` を付ける**
  → Vercel Analytics（プロジェクト `bcc`）でどの投稿から何人来たかを見る材料にする
- 同じサービスを続けない。カテゴリを回す（集客→財務→予約→教育…）

## 文面のルール（ポータル・Instagram と同じ恒久ルール）

- **料金は「約〇〇円」の目安で書く**（オーナー 2026-10-27「料金は約にしましょう」・オープンチャットだけの例外。
  実額のまま・「無料」は不可。数字は `writeups.json` の料金例を丸めたものだけ）。**サービス提供者の個人名を書かない**
- 断定的な効果の約束をしない。事実は `_build/writeups.json` の範囲だけ
- `render.mjs` が「約」の無い料金・「無料」・キリル文字・リンク無し・要点4つ以上を**機械で止める**
